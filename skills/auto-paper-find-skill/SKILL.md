# 准备论文输入

交付真实文件，让用户可以直接在 auto-paper-collector 的输入区粘贴或导入。支持“那篇提出 Transformer 的文章”等模糊线索，也支持“近五年关于某主题的十篇论文”等选题要求。

## 找到项目与输入约束

优先使用用户指定的项目，否则从当前工作目录及其父目录寻找 `paper_endnote/inputs.py`；本机已知位置为 `C:/Projects/auto-paper-collector`。不存在时询问项目路径，不冒充已完成兼容性验证。

先读项目的 `paper_endnote/inputs.py`、`tests/test_inputs.py` 和 README 的输入格式段落；涉及下游匹配能力时读 `paper_endnote/pipeline.py` 的 `_resolve_metadata`。以当前源码为准。生成前读取 [输入约束与工具用法](references/input-contract.md)。

## 把线索变成具体论文

- **清单模式**：逐条提取 DOI、题名片段、作者、年份、会议、研究对象等线索，保留用户顺序。不要把一条线索的多个候选都当成用户要的论文。
- **要求模式**：当用户没有提供具体论文清单、只给出模糊选题要求时，提取主题、时间范围、篇数、文献类型、语言、排除条件和筛选偏好。将“近几年”“最新”等转换成相对于执行日期的明确区间并告知用户。篇数未指定时默认最多 10 篇候选，说明这个假设；“全部”“系统综述”不适用这个默认，也不要宣称检索完整。
- 在要求模式中扩大候选池后再排序。主题相关性和证据质量相近时，默认提高目标领域公认顶级期刊、旗舰会议论文的优先度。根据论文所属学科判断 venue，不要套用单一学科名单或凭印象宣称“顶刊/顶会”；用户指定 venue、范围或排序规则时，以用户要求为准。venue 声望是排序信号，不得压过研究主线的实际匹配度，也不得排除重要的专门期刊、奠基工作或尚无正式发表版的新工作。
- 要求模式的入选判断不能只看题名。尽量取得每个候选的正式 abstract 并阅读，归纳其研究问题、对象或数据、方法、主要结论或贡献，以及它在用户主题中的角色（如奠基、方法、应用、评测或综述），据此判断文章主线和需求是否一致。abstract 不可获得时不得推测内容；标记证据不足，并在有充分替代候选时降低优先级。不要把 abstract 原文大段复制到交付物。
- 只有缺失信息会显著改变结果时才提问，例如完全没有研究主题，或两个候选都满足同一线索。继续处理独立且明确的条目。选题足够清楚时直接开始，不逐项请求批准。
- 模糊清单及要求模式需要实际联网检索。可用现有搜索工具、Crossref 或出版方公开接口；不依赖付费插件。优先核对出版方文章页、Crossref 元数据、官方会议论文集或预印本原始页面。搜索摘要用于找线索，不能单独充当身份确认依据。
- 对每篇确认正式题名、DOI（如存在），用作者、年份、会议等区分同名论文。保留原文题名，不把中文描述或自行翻译当成正式题名。不得按记忆猜 DOI、年份或作者，不得用主题关键词补足篇数。
- DOI 与题名必须对应同一版本。默认合并同一工作的预印本与正式发表版并优先正式版，除非用户要求预印本或比较版本；同名但不同工作的论文不能草率合并。按规范 DOI 去重，无 DOI 时按正式题名、年份和作者复核，并合并已确认属于同一论文的 DOI 行与题名行。
- 为每篇保存支持其身份及筛选条件的来源链接。需要“高被引”等排序时核实指标来源和查询日期；没有数据不能编造排名。纯格式转换且用户已给出完整题录时可以不联网，但标记为“仅格式校验，未联网核实”。
- 无法确认的条目放入独立待确认清单，解释歧义和候选，不混入可导入文件。数量不足时交付已确认部分并说明缺额；一篇都不能确认时不要生成空的“可用”清单。
- 联网不可用时不声称已核实。仍可转换用户提供的明确 DOI／完整题名，说明验证范围；只有模糊线索时保留待确认项，等待检索条件。

## 生成与验证

默认生成 CSV；用户指定 TXT 或同时要两种时遵从。除非用户另给路径，输出到项目 `outputs/paper-input/<YYYYMMDD-HHMMSS>/`，使用有意义的文件名。解释、引用链接、置信度、待确认项不写进导入文件。

将确认的记录整理为 JSON 数组，每项仅含 `doi,title,year,author`，空值使用 `null` 或空字符串。使用本 skill 的 `scripts/build_input.py` 写出文件。脚本只使用 Python 标准库，并从指定项目动态加载实际的输入解析器；运行方式见参考文件。不要运行项目服务来验证格式。

脚本要求解析后的记录数及字段与预期一致，捕获 CSV 分隔符猜测、TXT 误识别为表头、重复记录被静默丢弃等问题。TXT 无法无损表达某条题名时交付 CSV 并说明原因，不改写真实题名来绕过检查。格式检查不证明论文存在，也不保证后续下载成功。

如有检索、筛选、合并或排除，另存同名 `.sources.md`：列出筛选口径与日期、每篇原始线索到已确认题录的对应关系、venue、基于 abstract 的一句话主线判断、来源链接、未确认项及原因。无法取得 abstract 时明确写出，不用题名补写主线。CSV 中无 DOI 的正式题名可以导入，但项目可能仍需人工确认匹配；非 Crossref DOI／预印本也应说明下游解析限制，不承诺自动成功。

最终用用户语言给出文件链接、可导入数量、待确认数量及关键假设，简述格式校验与联网核实是否通过。任务止于准备输入；仅在用户另有要求时启动采集、下载 PDF 或写入 Zotero/EndNote。
