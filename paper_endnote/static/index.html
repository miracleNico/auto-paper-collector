读取所选 collection 的题录和 PDF，生成 records.xml / records.ris / PDF 子目录。默认写入 Downloads\[库名]。推荐在 EndNote 中导入 records.ris：File → Import → File，Import Option 选 Reference Manager (RIS)，Text Translation 选 Unicode (UTF-8)。不要导入 ZIP，也不要用默认的 EndNote Import。
